# Markus — play in your browser

**Play:** https://intotheveil.github.io/markus/

A dark visual novel adapted from the novel-in-progress *Markus* by A. Damon: the prequel to *Last Seen*, in English
and 19 other languages. This repository holds only the compiled web build (Ren'Py 8.4.1). Source is private.

Content warning: ritual murder witnessed by a child, child abuse (confinement and starvation, told in narration),
body horror, self-harm and injections, poisoning, killings, and coercion (in dialogue). An optional Mature mode
(18+, chosen at first launch, changeable in Preferences) shows the violence against adult characters on screen.
Scenes involving children are never shown graphically, in any mode, and sexual violence is never shown.
